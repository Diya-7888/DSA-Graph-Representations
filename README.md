# Graph Representations and Traversal in C

## Aim

To implement graph representation using an adjacency matrix and an adjacency list, and perform BFS, DFS, and vertex searching.

## Description

This project implements an undirected graph containing six vertices: A, B, C, D, E, and F.

The edges are:

* A – B
* A – C
* B – D
* B – E
* C – F
* E – F

The project uses two graph representations:

1. Adjacency Matrix
2. Adjacency List

## Operations

* Represent the graph using an adjacency matrix.
* Represent the graph using an adjacency list.
* Perform Breadth-First Search (BFS).
* Perform Depth-First Search (DFS).
* Search for a specified vertex.

The project demonstrates two ways of representing a graph in C. It compares their memory usage and traversal performance and shows how BFS, DFS, and vertex searching work.
